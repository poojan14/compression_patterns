Part A · Image Compression

1. Why compress? The three redundancies

A compression system has an encoder (turns the image into symbols) and a decoder (rebuilds the image from those symbols). The encoder removes three kinds of redundancy:

Coding redundancy

Frequent gray levels get the same long code as rare ones. Fix: variable-length codes (Huffman, LZW).

Interpixel redundancy

Neighbouring pixels are almost the same. Fix: predict or transform (RLE, DCT, DWT).

Psychovisual redundancy

The eye ignores fine detail it cannot see. Fix: quantization, which throws that detail away.

Try it: what quantization does

Twelve pixel values are rounded to multiples of a step size. A step of 1 changes nothing. Larger steps discard more detail, which leaves fewer distinct values, and fewer distinct values are cheaper to code.

3. Run-Length Encoding (RLE), lossless

Idea: replace each run of identical symbols with a (count, symbol) pair. It works well when long runs exist, as in binary images, fax pages, and simple graphics.

Example: AAAABBBCCDAA becomes 4A3B2C1D2A.

Limitation: this demo writes counts as digits, so it assumes the input has no digits. Real codecs store counts as binary bytes.

Application: fax machines (CCITT), BMP/PCX/TIFF packbits, scanline encoding in medical binary masks.

4. Huffman coding, lossless, variable-length

Idea: count how often each symbol appears. Repeatedly merge the two least frequent items into a tree. Left edges are 0 and right edges are 1. Frequent symbols end up near the root and get short codes.

Key property: the codes are prefix-free. No code is the start of another code, so the bit stream decodes without separators.

Application: the entropy-coding stage of JPEG, MP3, DEFLATE (ZIP, PNG, gzip).

5. Lempel-Ziv-Welch (LZW), lossless, dictionary-based

Idea: the encoder and decoder build the same dictionary as they go. The encoder keeps extending a buffer w while w+c is already in the dictionary. When it is not, it outputs the code for w and adds w+c as a new entry. No dictionary is transmitted.

Application: GIF, TIFF, and early PDF/PostScript.

6. JPEG: the whole pipeline, step by step

JPEG is lossy. It combines RLE-style zero coding, Huffman entropy coding, and a DCT transform. Use the buttons to walk through one 8×8 block. Move the quality slider to see how quantization changes everything.

7. Patterns and pattern classes

In recognition, each segmented image region is treated as an object, and each object is described as a pattern. So object recognition becomes pattern recognition: assign every pattern to its class.

Descriptor / feature

A measurable property of an object, such as length, width, area, or brightness. Good descriptors separate different classes clearly, whatever the object's position.

Pattern

An arrangement of descriptors that describes one object, for example x = [x₁, x₂, …, xₙ]ᵀ.

Pattern class ω

A family of patterns that share common properties. With W classes we write ω₁, ω₂, …, ω_W.

Three ways to arrange a pattern

Pattern vector: a list of numbers. Classic example: an iris flower described by x = [petal length, petal width]. Each flower becomes one point in a 2-D feature space, and the three varieties form three clusters: ω₁ = setosa, ω₂ = virginica, ω₃ = versicolor. You can play with this exact data set in Section 8.

Best when the object can be summarised by measurements.

String: a sequence of primitive symbols. A staircase boundary built from two primitives, a = step right and b = step down, is described by the string …ababab….

Best for structures with simple connectivity, usually boundary shapes.

Tree: a hierarchy that describes how a scene is composed. Example: a satellite image of a city.

8. Decision-theoretic methods

We want W decision functions d₁(x), …, d_W(x). An unknown pattern x belongs to class ωi if dᵢ(x) > dⱼ(x) for every j ≠ i. In words: substitute x into every decision function, and the largest value wins.

The decision boundary between classes i and j is where dᵢⱼ(x) = dᵢ(x) − dⱼ(x) = 0. Patterns of ωi give dᵢⱼ(x) > 0 and patterns of ωj give dᵢⱼ(x) < 0.

8.1 Matching: minimum-distance classifier

Each class is represented by a prototype mj (the mean of its training patterns). The unknown is assigned to the nearest prototype using Euclidean distance D = √Σ(xᵢ − yᵢ)². This is the same as using the decision function dⱼ(x) = xᵀmⱼ − ½ mⱼᵀmⱼ and taking the largest.

Try it: click or tap anywhere on the plot to place an unknown flower. The coloured background shows which class every point would be given; the borders between colours are the decision boundaries (perpendicular bisectors between prototypes).

Limitations of template matching: the object must be well segmented, results are sensitive to lighting and background clutter, and performance drops sharply with occlusion, rotation and scale changes.

8.2 Optimal statistical (Bayes) classifier

Image data is uncertain (lighting, occlusion, viewpoint), so we use probabilities. Bayes' theorem gives the posterior probability P(ωᵢ|x) = p(x|ωᵢ) P(ωᵢ) / p(x). Assign x to the class with the largest posterior. This gives the minimum probability of error on average.

Since p(x) is the same for every class, the Bayes decision function is simply dⱼ(x) = p(x|ωⱼ) P(ωⱼ). For 1-D Gaussian classes: dⱼ(x) = (1 / √(2π) σⱼ) · e−(x − mⱼ)² / 2σⱼ² · P(ωⱼ).

Try it: move the sliders. Watch the boundary (where the two curves cross) shift when you change a prior or a spread.

Application (from the slides): classifying a multispectral aerial image into vegetation, water and bare soil. Each pixel is a pattern vector of its brightness in several spectral bands, and a Gaussian Bayes classifier labels every pixel.

9. Neural networks

A neural network is made of neurons in layers: an input layer, one or more hidden layers, and an output layer. Training (learning) uses a training set to find the weights, which together form the decision function. Instead of hand-designing features, a deep network learns a hierarchical non-linear function f(I) that maps an image I to class probabilities. The final decision picks the class with the maximum posterior probability.

History: interest began in the 1940s. In the 1950s and 1960s Rosenblatt proposed the perceptron as a learning machine.

9.1 Perceptron (Rosenblatt)

One neuron: multiply each input by a weight, add them, and compare with a threshold T. y = Σ xᵢwᵢ, output = 1 if y > T, else 0. Its decision boundary w₁x₁ + w₂x₂ = T is a straight line, so it can only separate linearly separable classes.

Try it: pick a problem, then press Train. The learning rule is w ← w + η(t − o)x and T ← T − η(t − o), with η = 0.1. AND and OR converge. XOR never does.

9.3 Multilayer perceptron (MLP)

An MLP (feedforward network) stacks layers of perceptrons. The hidden layers let it learn non-linear boundaries, so it can solve problems like XOR that a single perceptron cannot. The textbook example (Fig. 12.19) recognises four shapes using an input pattern vector, layer A with 48 neurons, layer B with 26 neurons, and an output layer Q with 4 neurons, one per shape.

Every neuron connects to every neuron in the next layer. Training (back-propagation) adjusts the weights wba and wqb.

9.4 Convolutional neural network (CNN)

CNNs are neural networks designed for images. Typical flow: convolution → ReLU → pooling → (repeat) → fully connected → class scores (dog / cat / lion / bird).

Convolution layer

Slides small filters (kernels) over the input. Each filter produces a feature map showing where its feature (edge, texture, …) appears. Does most of the computation.

Pooling layer

Max or average over small windows. Shrinks width and height, reduces computation, and helps control overfitting.

Fully connected

Flattens the final feature maps and maps them to class scores, usually with softmax at the end.

10. Case studies: YOLO and Faster R-CNN

Case study 1: YOLO (You Only Look Once)

  • A single CNN looks at the whole image once and predicts all bounding boxes and class probabilities at the same time (one-shot detection).
  • The image is divided into an S × S grid. The cell that contains an object's centre is responsible for detecting it.
  • Each box has a confidence score defined by the IoU (Intersection over Union) between the predicted box and the ground truth.
  • Because it sees the whole image during training and testing, it learns context about classes and where they appear.
  • Speed: the base model runs at 45 frames/s and Fast YOLO at 155 frames/s, so it suits real-time use.
  • Weakness: lower accuracy on small objects and objects that appear in groups.

Try it: change the grid size and move the predicted box. The yellow cell is responsible for the object, and IoU updates live.

Case study 2: Faster R-CNN

A two-stage detector. A Region Proposal Network (RPN) inside the network suggests where objects might be, then a second stage classifies each proposal. Click each stage.

RoI pooling: any proposal size → one fixed size

Proposals have different sizes, but the classifier needs a fixed-size input. RoI pooling divides each proposal into a fixed grid (here 2×2) and takes the max in each part.

11. Structural methods

Structural methods use the relationships inherent in a pattern's shape rather than numbers alone. Three methods: syntactic recognition of strings, matching shape numbers, and string matching.

11.1 Syntactic recognition of strings

Three ingredients: (1) a set of pattern primitives, (2) a grammar of rules for how they connect, and (3) a recognizer (automaton) built from that grammar.

A string grammar is a 4-tuple G = (N, Σ, P, S): N = non-terminals (variables), Σ = terminals (constants, the primitives), P = productions (rewriting rules), S = starting symbol.

Example (Fig. 12.26): N = {S, A, B}, Σ = {a, b, c}, P = {S → aA, A → bA, A → bB, B → c}. The primitives are a (left end), b (a short straight segment) and c (right end) of an object's pruned skeleton. This grammar generates only strings of the form abⁿc (n ≥ 1).

The slide shows "B → C" with a capital C. It should be a lower-case c, because c is a terminal; once it is applied no non-terminals remain and the derivation ends.

Use of semantics

Syntax (the productions) fixes the structure. Semantics, stored in a knowledge base, check the correctness: lengths, directions, and how many times a rule may be used.

Type any string. The automaton q0 —a→ q1 —b→ q2 (b loops on q2) —c→ qF accepts exactly the strings of L(G). The semantic check then limits the number of b's.

Applications: anything describable by well-defined rules, for example speech recognition (phoneme sequences as automaton states), chromosome and character shapes.

11.2 Matching shape numbers

Like the minimum-distance idea, but for region boundaries described by shape numbers.

Freeman 4-direction chain code: 0 = right, 1 = up, 2 = left, 3 = down.

  1. Write the chain code of the boundary.
  2. First difference: for each element, (current − previous) mod 4. The first element is compared with the last (the boundary is closed). Example: 2 − 3 = −1, and −1 mod 4 = 3.
  3. Shape number: rotate the difference cyclically until it forms the smallest number.
  4. Order n = number of digits in the shape number.

The difference makes the code independent of rotation, and choosing the smallest rotation makes it independent of the starting point.

Presets:

Degree of similarity k and distance D

Two shapes a and b have degree of similarity k if their shape numbers agree for every order 4, 6, 8, …, k and differ for k + 2, k + 4, …. The distance is D(a, b) = 1 / k. It satisfies D ≥ 0, D = 0 only if a = b, and D(a, c) ≤ max[D(a, b), D(b, c)]. Higher k (lower D) means more similar.

11.3 String matching

Code two region boundaries as strings a = a₁a₂…aₙ and b = b₁b₂…bm. Let α = number of positions where the symbols match. Then the number of mismatches is β = max(|a|, |b|) − α, and the similarity is R = α / β. If the strings are identical, β = 0 and R is infinite. Larger R means more similar.
